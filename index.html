Dados integrados e previsão de demanda para o S&OP de Personal Care

O Módulo 1 reúne num data lake, no Azure da Essity, as fontes de venda, estoque, preço e mercado, e organiza os dados nas camadas bronze, prata e ouro. O Módulo 2 acrescenta um modelo que prevê a demanda de Personal Care por SKU e canal para o rolling forecast do S&OP mensal.

O protótipo navegável precisa de JavaScript. Ative o JavaScript no navegador para abrir as telas. Todos os dados do protótipo são ilustrativos.
